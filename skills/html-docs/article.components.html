Structure

This is a lead card. It carries card--lead, so it is not numbered and never renders 00. It is the only card open on load.

Every other card below demonstrates one component. Open a card, then read its markup in the source.

The header is a real button with aria-expanded. The number is generated by a CSS counter, so inserting a card never renumbers by hand.

The second header line is a subtitle. Use it when the title alone does not make a collapsed card understandable.

Use a reveal for troubleshooting, evidence, derivations, and side arguments. The content stays inline in the HTML, so it prints and searches.

Reveal body text stays at normal reading size. Optional does not mean fine print.

  • Check the resource provider registration first.
  • Then confirm the role assignment has propagated.

Reveals are independent of each other and of the card.

Without JavaScript, the tab strip is hidden and every panel is shown stacked with its label, so nothing is lost.

Migration doubles the running footprint for the cutover window. Budget for the overlap rather than the end state.

The platform absorbs patching and node health. In exchange, diagnosis moves from the host to the platform log surface.

Shaped content

Sequence

  1. Virtual machinesFull control, full responsibility.
  2. ContainersPortable units, orchestrated.
  3. Managed platformOperations absorbed.

Steps

  1. Provision

    Create the resource group and the workload identity.

  2. Deploy

    Push the image and roll out the first revision.

  3. Verify

    Confirm the health probe returns 200 before shifting traffic.

Latency

Median request time drops once the cold start is removed.

Cost

Steady state is cheaper; the migration window is not.

Risk

The rollback path must be rehearsed before the cutover.

Effort

Most of the work is in configuration, not in code.

Next actions

  • Run the readiness assessment against the staging subscription.
  • Record the current baseline latency before changing anything.
  • Agree the rollback trigger with the service owner.
