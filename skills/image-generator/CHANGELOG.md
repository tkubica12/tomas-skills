# Changelog

## 0.2.0 — 2026-10-14

- Portable optional MIT adaptation; offline planning and no mandatory chat model.
- Agent-authored complete prompts by default; explicit catalog-verified compiler.
- Read-only lazy Azure discovery with explicit config/current identity precedence.
- Actual provider/model/version selection, documented family adapters, catalog
  lifecycle/capability checks and actionable absent/ambiguous/legacy decisions.
- Strict native dimensions, unmodified references, current MAI edit support with
  explicit uncontrolled-size verification choice, and Entra-only authentication.
- Content-addressed prompt/image cache; immutable originals, reference archives,
  model/returned-size metadata, atomic run manifests and failure/retry lineage.
- Bounded visible 429/503 retries; no replay after uncertain transport delivery.
- Fake-backed tests; newly resolved Microsoft-feed lock, no paid validation calls.
- Locked-runtime validation: 41 passing tests and installed-wheel offline CLI;
  explicit regression coverage for pre-paid-call MAI 4K rejection and unknown
  family rejection, with preflight preserving injected notification handlers.
- Optional document-review handoff guidance: exact candidate count, immutable
  asset-root paths, review hashes/anchor and request/generation/parent lineage;
  no favorite application, source edits or silent native-resolution resizing.

## Adaptation baseline

The read-only source package identified itself as 0.1.0. Its selected deployment
defaults, size normalization and public-PyPI lock are intentionally not retained.
